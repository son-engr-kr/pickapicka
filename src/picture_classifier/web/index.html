    Subject detection

    Pick what this project is a shoot of. Detected subjects drive three things: photos without one sort down, sharpness is measured on the subject instead of the whole frame, and look-alike subjects get grouped so you can filter by them.

    Groups

    Grouping is by appearance — colour and how it sits on the shape. Two cars of the same colour and shape will land in one group; rename or hide anything it gets wrong.

    Apply adjustments to many

    Apply an edit to several photos at once. Non-destructive — the originals are never modified.

    Photos not found

    This project's photo folder isn't where it used to be (moved, renamed, or on a drive that's disconnected). Pick the new location and I'll re-link the photos — matching by folder structure first, then by file name for anything that moved around.
